## S-01 · Can a shell load a module's view and script on demand inside the HtmlService sandbox?

**Question.** Can an already loaded page ask the server for one module (view, style, script), add it, and run it, once, without `import`? (AD-03.)

**Method.** The page starts with no module code. Tapping "Open alpha" calls the server, adds the view and the style, adds the script as a script element (and, only if that fails, tries `new Function`), calls `init()`, and logs the time, the method used and whether the style applied. A second tap must not fetch again.

**Fallback if it fails.** Ship all module code in the first load (AD-03 fallback).

## S-05 · Does device storage persist inside the web app iframe on iOS Safari and Android Chrome?

**Question.** Do `localStorage` and `sessionStorage` work inside the sandboxed iframe, and does a stored draft survive a reload, a closed tab and a closed browser app? (ARCHITECTURE §1.5, risk 8.)

**Method.** The page writes a small test draft (a random id, no real data) to both stores and reads it back after each step.

**Fallback if it fails.** Offline drafts degrade to an in-memory warning (§1.5). No other function depends on storage.
